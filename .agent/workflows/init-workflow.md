# Workflow d'Initialisation & Cadrage PRD (init-workflow)

## Objectif
Guider l'équipe et l'utilisateur dans la formalisation des besoins et la levée du garde-fou PRD avant tout développement.

## Étapes
1. **Écoute & Cadrage Métier** : Analyser les besoins cliniques, ergonomiques et techniques.
2. **Rédaction du PRD** : Compléter exhaustivement les sections de `00_Conception_et_References/01_PRD.md`.
3. **Revue avec l'Utilisateur** : Présenter les choix sous forme de propositions claires.
4. **Validation Formelle (Garde-fou)** : L'utilisateur coche la case `[x] PRD Validé` dans `01_PRD.md`.
5. **Déblocage du Code** : Transition vers le workflow de développement (`dev-workflow.md`).
