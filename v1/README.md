# 🛡️ ErgoVision AI — Version 1.0.0 (Archive Stable)

Ce dossier conserve l'état exact et autonome d'**ErgoVision AI v1.0.0** (gelé le 15/10/2026).

## Caractéristiques de la V1
- Copilote biomécanique en temps réel (MediaPipe Pose Wasm/WebGL).
- Calibration "Point Zéro" personnalisée (cervicales, trapèzes, inclinaison latérale).
- Pacing multi-modes : Bureau Assis, Bureau Debout, Pause & Étirement (avec défilement négatif *Overtime*).
- Boucle sonore continue douce / pulsée s'éteignant instantanément au retour en posture neutre.
- Carillon harmonieux de fin de cycle (Do-Mi-Sol).
- Interface Fluent UI 2 Mica/Acrylique avec bascule Sombre/Clair.
- Internationalisation bilingue intégrale (Français / Anglais).
- Télémétrie locale quotidienne persistée (`localStorage`) avec export CSV.
